# Sharing View-Only Links with Clients

## How to Share

### From the Editor Page:
1. Open any panorama in the editor (`/editor/<id>`)
2. Click the **"Share"** button (🔗) in the top-right corner
3. Copy the view-only link from the modal
4. Share this link with your clients

### Direct URL Format:
```
http://your-domain.com/view/<panorama_id>
```

Example: `http://your-domain.com/view/1`

## What Clients Can Do

✅ **View-only mode includes:**
- Full panorama viewing
- Zoom in/out (mouse wheel or buttons)
- Pan/drag to explore
- Click plots to see details (name, area, price, status, description)
- All plot markings are visible

❌ **What's hidden:**
- Edit mode toggle
- Drawing tools
- Plot creation/editing
- Delete buttons
- Back to dashboard button

## Features

### View-Only Page Features:
- **Clean Interface**: No edit controls, just viewing
- **Share Button**: Clients can also share the link
- **Interactive Plots**: Click any plot to see full details
- **Zoom Controls**: Standard zoom in/out/reset buttons
- **Instructions Panel**: Helpful hints for navigation

### Editor Page Features:
- **Share Button**: Easy access to generate view-only links
- **Copy to Clipboard**: One-click copy of the share link
- **Full Edit Access**: Create, edit, and delete plots

## Use Cases

1. **Client Presentations**: Share interactive panoramas during meetings
2. **Property Showcases**: Let clients explore plots independently
3. **Sales Materials**: Include links in emails or presentations
4. **Public Viewing**: Share with multiple stakeholders without edit access

## Security Notes

- View-only links are **public** - anyone with the link can view
- No authentication required for view-only mode
- Consider adding authentication if you need private sharing
- Plot data is visible to anyone with the link

## Tips

- **Bookmark**: Clients can bookmark the view-only link
- **Mobile Friendly**: Works great on tablets and phones
- **Share Modal**: Use the share button to easily copy links
- **Direct Links**: You can also construct URLs manually if needed
